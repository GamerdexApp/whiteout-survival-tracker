# Whiteout Survival Tracker

A progress tracker for Whiteout Survival. Keep several Chiefs, plan upgrades for each game area and keep the data in your browser. Optional sync across devices comes in a later phase.

Built with Next.js 16, React 19 and Tailwind CSS 4. The game data comes from the `whiteout-survival-data` package.

## Status

The app shell is built. Chiefs, Settings and the game pages follow in phases.

## Design

The design plan and the boards are in the private `gamerdex-plan` repo, folder `whiteout-survival-tracker/`.
